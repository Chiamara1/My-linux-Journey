## SHELL SCRIPTING
Shell scripting is writing a series of commands inside afile so Linux can execute them automatically.
Linux and Shell scripting work Hand in Hand.

## SHELL SCRIPTING COMMANDS
To create empty files and update timestamps
```
TOUCH
```
To list out files in your current directories
```
LS
```
To list out files with 
```
LS -LTR
```
To list user manuals for linux commands
```
MAN
```
To Edit a file
```
VIM or VIM
```
First syntax used in a shell script
```
#!/(SHEBANG)
```
